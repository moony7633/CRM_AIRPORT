# Аэрофлот · Умная диспетчеризация ОТО

Прототип для конкурса: диспетчер видит борт, стоянку и свободных инженеров,
система сама выбирает ближайшего подходящего техника, ведёт его по рулёжным
дорожкам и считает норматив 15 минут.

## Что внутри

- **Реальные карты Шереметьево (SVO/UUEE) и Домодедово (DME/UUDD)** из
  OpenStreetMap: ВПП, рулёжные дорожки, перроны, терминалы, ангары и все
  места стоянок. Для симуляции выбираются 18 стоянок главного перрона.
- **2D-карта** (SVG) и **3D-вид** (canvas, без Three.js и внешних библиотек,
  чтобы работало офлайн и на слабых ТСД).
- **Подбор техника** по квалификации (`Планер`, `Двигатель`, `Авионика`),
  допуску на тип ВС и кратчайшему маршруту по графу рулёжных дорожек.
- **Норматив 15 минут**, ЧС, очередь заявок, работа, устранение, журнал.
- Самолёты, спецтехника (GSE), маршруты, блокировка участков.
- Демо-состав смены с вымышленными ФИО — см. [`data/STAFF.md`](data/STAFF.md).

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

python run.py --airport data/airport_sheremetyevo.json
# открыть http://127.0.0.1:8000
```

3D сразу: <http://127.0.0.1:8000/?view=3d> или `#3d`.
Домодедово: `python run.py --airport data/airport_domodedovo.json`.

### Windows

Скачайте/распакуйте архив и запустите `START-WINDOWS.bat` — он создаст
окружение, установит зависимости и предложит выбрать аэропорт. Подробная
инструкция: [`README-WINDOWS.txt`](README-WINDOWS.txt).

Кнопка **3D/2D** — правый верхний угол карты. В 3D: перетаскивание — поворот,
колесо/пинч — масштаб, двойной клик — вернуться к перрону.

## Пересобрать карту из OSM

Нужен интернет. Данные © участники OpenStreetMap, лицензия ODbL —
указывайте это в презентации.

```bash
# напрямую с OSM API (работает, когда Overpass перегружен)
python tools/osm_to_airport.py --bbox 37.32,55.96,37.46,55.99 \
    --name "Шереметьево (SVO · UUEE)" --max-stands 18 \
    --out data/airport_sheremetyevo.json

python tools/osm_to_airport.py --bbox 37.86,55.39,37.96,55.43 \
    --name "Домодедово (DME · UUDD)" --max-stands 18 \
    --out data/airport_domodedovo.json

# если уже есть выгрузка OSM XML — без интернета
python tools/osm_to_airport.py --input svo.osm --out data/airport_sheremetyevo.json

# через Overpass по ICAO (если Overpass доступен)
python tools/osm_to_airport.py --icao UUEE --out data/airport_sheremetyevo.json
```

Порядок `--bbox`: `minlon,minlat,maxlon,maxlat` (как у OSM API).
Скрипт собирает мультиполигоны терминалов, поэтому у Домодедово и
Шереметьево на карте есть реальные контуры терминалов.

## Инженеры и допуски

`data/technicians.json` — 9 человек демо-смены. У каждого:

```json
{"name": "Иванов П. С.", "qual": "Планер", "types": ["A320", "B737", "SSJ-100"],
 "speed": 4.0, "base": "BASE1"}
```

`types` — допуски на типы ВС. Если борт на стоянке имеет тип, которого нет
у техника, он не назначается; в таблице кандидатов видно причину
«нет допуска на A350». Для каждой квалификации в демо покрыты все типы
из парка: A320, B737, B777, A330, A350, SSJ-100.

Реальные ФИО сотрудников не публикуются в открытых источниках, поэтому имена
вымышленные. Что нужно уточнить у организаторов/перевозчика — в
[`data/STAFF.md`](data/STAFF.md).

## Ограничения прототипа

- GPS не используется: маршрут считается по графу рулёжных дорожек, поэтому
  системе не страшны глушилки GPS. Реальное положение можно добавить позже.
- Техники ходят/едут с постоянной скоростью из конфига; отдельного режима
  «пешком или спецтранспорт» пока нет.
- 3D минимальное: контуры и высоты зданий без текстур и мелкой детализации.
- Парковка и крытые перроны не моделируются.
